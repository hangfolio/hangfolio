# hangfolio

A personal website for researchers and engineers, built with Astro and published on GitHub Pages. You copy a template repository, edit one settings file and a `content/` folder in the browser (papers come straight from a BibTeX file), and the site rebuilds itself on every commit. The design, pages, validation and deploy machinery live in this repository and reach every site through the `hangfolio` npm package and two reusable workflows.

**Work in progress.** Nothing here is ready to use yet.
