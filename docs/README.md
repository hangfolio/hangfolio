# hangfolio docs

A personal website for researchers and engineers, published on GitHub Pages. You edit text files in
the browser; every commit is checked, built and published.

**New here?** Start with the [Quickstart](quickstart.md): 5 steps, about 10 minutes, nothing to install.

| Page | What it covers |
|---|---|
| [Quickstart](quickstart.md) | The 5 steps, moving from an existing `username.github.io` site, and working in a terminal |
| [Editing your site](editing.md) | Every file you edit, one section each |
| [The site.yaml reference](site-yaml.md) | Every setting in `site.yaml` |
| [Publications](publications.md) | BibTeX, pasting from Google Scholar, extras and papers in preparation |
| [Custom domain](custom-domain.md) | Using your own domain name |
| [Updating](updating.md) | Theme updates through Dependabot, versions, pinning |
| [Customizing](customizing.md) | Sections, pages, the menu, colour and your own CSS |
| [Local preview](local-preview.md) | Codespaces, or Node on your computer |
| [Moving an existing site](existing-site.md) | From academicpages or al-folio, by hand |
| [Troubleshooting](troubleshooting.md) | Every message code, and GitHub Pages problems |
| [FAQ](faq.md) | What's public, private repositories, forks, costs |

These pages are versioned with the theme: links in error messages open the docs for the exact
version your site uses. Questions go to the
[discussions](https://github.com/hangfolio/hangfolio/discussions).

[`decisions/`](decisions/README.md) holds the project's design notes, for contributors.
