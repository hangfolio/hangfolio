GitHub Pages setup

Almost there

This site is being set up. If it is yours, one setting in GitHub finishes the job:

  1. Open your repository’s Settings → Pages.
  2. Under Build and deployment → Source, choose GitHub Actions. Do not click Configure on a suggested workflow: your repository already has one.
  3. Open Actions → Deploy site and click Run workflow. About two minutes later, your site replaces this page.

You see this page because GitHub Pages is publishing the files in your repository as they are (Deploy from a branch). Your site is built by GitHub Actions instead.

Still here after the steps? Reload the page: GitHub can keep an old copy for up to 10 minutes.
