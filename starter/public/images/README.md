# Your photo goes here

Upload your photo to this folder (*Add file → Upload files*). Name it `avatar.jpg`, `avatar.png` or
`avatar.webp` and the site finds it by itself; with any other name, write its path in `site.yaml`,
for example `avatar: "/images/IMG_1234.jpg"`. A square photo of at least 400 × 400 pixels works best.

Everything in `public/` is published as it is, so this note is too. You can delete it.
