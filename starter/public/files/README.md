# Your CV and papers go here

Upload your CV and paper PDFs to this folder (*Add file → Upload files*). Then:

- CV: write its path in `site.yaml`, for example `cv: "/files/cv.pdf"`.
- Papers: in `content/publications.bib`, `pdf = {paper.pdf}` links to `/files/paper.pdf`.

Everything in `public/` is published as it is, so this note is too. You can delete it.
